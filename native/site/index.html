mcbench-lite

An app in which AI models build in Minecraft 1.21.10. It runs on macOS, Windows and Linux, and keeps your chats and worlds on your computer.

Install on macOS Windows Linux

Install on macOS

curl -fsSL https://adonis-singh.github.io/mcbench-lite/install.sh | sh

Paste into Terminal. About a minute.

The app goes to the Applications folder in your home folder and starts. It updates itself: it downloads and checks each new version in the background and switches to it the next time it starts.

Uninstall

curl -fsSL https://adonis-singh.github.io/mcbench-lite/install.sh | sh -s -- --uninstall

This removes the app, what macOS keeps for it, ~/.cache/mcbench and the app's leftover temporary folders. The data folder ~/Library/Application Support/mcbench-lite, with your chats, worlds and settings, stays, and so do Claude Code's transcripts of the app's chats and the Codex sign-in file ~/.codex/auth.json, which are yours; the uninstall prints where each one is.

Install on Windows

irm https://adonis-singh.github.io/mcbench-lite/install.ps1 | iex

Paste into PowerShell. About a minute.

The app is installed for your account only, with no administrator, and starts. On the first run it asks once for an administrator's approval to set up WSL, which the model's bash shell and the build tool run in, and on most computers Windows then needs one restart. On a computer where WSL already works, nothing is asked.

It updates itself: it downloads and checks each new version in the background and switches to it the next time it starts.

Or download the installer

Download installer (.exe)

The same installer the command runs. It is not signed, so Windows warns twice on this route: Edge holds the download back as one that "isn't commonly downloaded" until you choose to keep it, and when you open the file Windows says "Windows protected your PC", where More info shows Run anyway.

Uninstall

Settings > Apps > Installed apps > mcbench-lite > Uninstall, or in PowerShell:

& "$env:LOCALAPPDATA\Programs\mcbench-lite\uninstall.exe"

This removes the app, its own WSL distribution mcbench-lite (which holds nothing of yours), its cache folder and its leftover temporary folders. The data folder %LOCALAPPDATA%\mcbench-lite, with your chats, worlds and settings, stays, and so do Claude Code's transcripts of the app's chats and the Codex sign-in file .codex\auth.json in your user folder, which are yours.

Install on Linux

wget -qO /tmp/mcbench-lite.deb https://github.com/adonis-singh/mcbench-lite/releases/latest/download/mcbench-lite_$(dpkg --print-architecture).deb && sudo apt install -y /tmp/mcbench-lite.deb

Updates arrive with your system updates.

Download .deb: amd64, arm64

On Ubuntu 23.10 and later, use the .deb: it loads the AppArmor profile the model's bash and build need.

Uninstall

sudo apt remove mcbench-lite

Or the script or the AppImage

Both are under Other Linux. On Ubuntu 23.10 and later they need Ubuntu's AppArmor profile for bwrap, or the model's bash and build do not work: the script asks to install it with sudo, and for the AppImage install it with:

(cd "$(mktemp -d)" && apt-get download apparmor-profiles && dpkg-deb -x apparmor-profiles_*.deb . && sudo install -m 0644 usr/share/apparmor/extra-profiles/bwrap-userns-restrict /etc/apparmor.d/bwrap-userns-restrict && sudo apparmor_parser -r /etc/apparmor.d/bwrap-userns-restrict)
sudo dnf install -y https://github.com/adonis-singh/mcbench-lite/releases/latest/download/mcbench-lite.$(uname -m).rpm

Updates arrive with your system updates.

Download .rpm: x86_64, aarch64

Uninstall

sudo dnf remove mcbench-lite
yay -S mcbench-lite-bin

or paru -S mcbench-lite-bin

Updates arrive with your AUR helper.

Without an AUR helper:

git clone https://aur.archlinux.org/mcbench-lite-bin.git && cd mcbench-lite-bin && makepkg -si

Uninstall

sudo pacman -R mcbench-lite-bin
curl -fsSL https://adonis-singh.github.io/mcbench-lite/install.sh | sh

Installs into your home folder. Needs bubblewrap. No sudo, except on Ubuntu 23.10 and later, where it asks to install Ubuntu's AppArmor profile for bwrap with sudo.

Download AppImage: x86_64, aarch64. Make it executable with chmod +x and run it; it updates itself.

The script needs a glibc system on x86_64 or aarch64 and refuses musl systems such as Alpine. The app it installs updates itself.

Uninstall

curl -fsSL https://adonis-singh.github.io/mcbench-lite/install.sh | sh -s -- --uninstall

This removes the app, its link in ~/.local/bin, its menu entry and icon, ~/.cache/mcbench and the app's leftover temporary folders, and prints where the files it keeps are. An AppImage is removed by deleting the file.

The model's bash shell runs under bubblewrap (the package is called bubblewrap on every distribution).

Every uninstall keeps the data folder ~/.local/share/mcbench-lite (or $XDG_DATA_HOME/mcbench-lite), with your chats, worlds and settings, and Claude Code's transcripts of the app's chats and the Codex sign-in file ~/.codex/auth.json, which are yours. A package's removal also leaves ~/.cache/mcbench, which you can delete.
