# Source code of the sandbox's Linux userlands

The model's bash shell runs in a Linux root filesystem, and on macOS and Windows the app starts it from a small Linux guest base; both are made of Debian packages, many of them under the GNU GPL or LGPL. Their source code is published in the same GitHub release as the files themselves, the release named `sandbox-assets-<hash>` that the app downloads its root filesystem from, at https://github.com/adonis-singh/mcbench-lite/releases. The asset `sandbox-sources.tar` in that release holds the Debian source package of every Debian package in the guest base and the root filesystem, for x86_64 and aarch64, each checked against the hashes Debian published, with a list that names every binary package, its source package, its licence and the files of its source. The asset `passt-<version>.tar.gz` beside it is the source of pasta, the user-space network program in the root filesystem. The other parts of them (Python, NumPy, Pillow, pip and mcbench-lite's own sandbox agent) are under licences that do not ask for their source to be offered; the bundle's README says where each one's source is.
